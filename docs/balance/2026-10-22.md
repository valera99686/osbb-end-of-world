# Баланс 0.15.2

Перший відгук гравця (одна людина, веб-версія): гра нудна, немає градації складності, виграти легко на будь-якому рівні. Причина, яку вдалося встановити з коду: рівні загрози з’являлися лише після першої перемоги, тож новачок їх не бачив, а перші три рівні додавали по 8–15% на одну характеристику ворогів і майже не відчувалися.

## Що змінено

| Рівень | Було | Стало |
| --- | --- | --- |
| Доступність | рівень 1 після першої перемоги | рівні 0–3 з першого рейду, далі як раніше |
| 1 | здоров’я ворогів +10% | здоров’я +25% |
| 2 | ремонт +50% | ремонт +50%, шкода ворогів +15% |
| 3 | швидкість ворогів +8% | швидкість +12%, поява +10% |
| 4 | шкода +15% | шкода ще +20% |
| 5 | посилені вороги +6% | +10% |
| 6 | поява +15% | поява ще +20% |
| 10 | здоров’я ще +20%, шкода ще +15% | здоров’я ще +30%, шкода ще +25% |

Підсумок для ворогів (здоров’я / шкода / швидкість / поява):

| Рівень | Було | Стало |
| --- | --- | --- |
| 1 | ×1,10 / ×1,00 / ×1,00 / ×1,00 | ×1,25 / ×1,00 / ×1,00 / ×1,00 |
| 3 | ×1,10 / ×1,00 / ×1,08 / ×1,00 | ×1,25 / ×1,15 / ×1,12 / ×1,10 |
| 5 | ×1,10 / ×1,15 / ×1,08 / ×1,00 | ×1,25 / ×1,35 / ×1,12 / ×1,10 |
| 10 | ×1,30 / ×1,30 / ×1,08 / ×1,15 | ×1,55 / ×1,60 / ×1,12 / ×1,30 |

Рівень 0 не змінено (тест `heatEffects(0)` вимагає нейтральних значень), тому шість умов аудиту `scripts/balance-audit.cjs`, який грає на загрозі 0, цією зміною не зачеплені й не перезапускалися. Тести боїв оновлено під нові числа (`tests/combat-variety.test.cjs`), додано тест видимості складності (`tests/features.test.cjs`).

## Чого це не доводить

Число на кожному рівні — розрахунок, а не результат проходів. Чи стане гра справді складнішою на рівнях 3–10 і чи відчуватиметься різниця, покаже лише живий плейтест (протокол у `docs/qa/playtest.md`, шаблон журналу — `docs/balance/playthrough-template.md`). Рівень 0 тим, кому він здається легким, залишається таким: підвищувати його без проходів людиною не стали.
