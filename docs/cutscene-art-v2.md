# Нові ілюстрації катсцен

Створено вбудованим imagegen: шість окремих зображень для історії міських автоматів. Збережено стиль гри та форми бойових ворогів. Оригінальні PNG збережено в `docs/art-source/`; у грі використовуються WebP без втрат. Розмір і кожен декодований піксель перевірено на тотожність оригіналу. Так само оптимізовано попередній атлас катсцен і зображення міста 2086 року, щоб автономний APK відповідав обмеженню розміру файлу на хостингу.

| Сцена | Файл у проєкті |
|---|---|
| Мирні роботи обслуговують місто | [Місто до катастрофи](../public/art/origins-city-service-v1.webp) |
| Аварія обриває керування | [Збій мережі](../public/art/origins-network-failure-v1.webp) |
| Брухтар і Пресувальник атакують дім | [Атака збирачів](../public/art/origins-scrap-attack-v1.webp) |
| Гончак переслідує будинок, дрон стріляє | [Переслідування](../public/art/origins-drone-pursuit-v1.webp) |
| Коренехід і Кабелеріз біля теплиць | [Теплиці](../public/art/origins-greenhouse-machines-v1.webp) |
| Часове поле відновлює розібрані машини | [Часова петля](../public/art/origins-time-loop-v1.webp) |

Повні промпти: [місто, аварія та петля](art-prompts/origins-production-v1-prompts.txt), [три бойові сцени](art-prompts/cutscene-action-prompts-v1.json).

Нові зображення підключено до прологу та катсцени «Звідки взялися монстри». Вони входять до автономного кешу вебгри й Android APK. Підписи розташовані під ілюстраціями, щоб не перекривати важливі деталі.
