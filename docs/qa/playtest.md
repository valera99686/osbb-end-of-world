# Плейтест з одногрупниками

Протокол для задачі 3.4 з [WBS](../wbs/README.md). Мета: побачити, де нова людина без підказок застрягає, нудьгує чи гине. Потрібно 3–5 тестувальників і по 20–30 хвилин кожного.

## Підготовка

1. Дай посилання: <https://valera99686.github.io/osbb-end-of-world/> (веб) або APK з [релізу](https://github.com/valera99686/osbb-end-of-world/releases/latest). Для APK спочатку допоможи з дозволом на встановлення.
2. Новий профіль: окремий браузер чи вікно інкогніто, інакше прогрес твого профілю вплине на гру.
3. Ввімкни запис екрана, якщо людина не проти. Дані й імена не збираються: гра офлайн, нічого не передає, а у відгуку достатньо нікнейма.
4. Дай форму відгуку: [Відгук після гри](../../.github/ISSUE_TEMPLATE/playtest_feedback.md) (її можна вставити в чат чи заповнити усно).

## Під час гри: правила спостерігача

- **Не підказуй.** Якщо людина питає «як це працює?», відповідай «а як ти думаєш?» і запиши, де вона застрягла. Підказуй лише після двох хвилин безрезультатності.
- **Не пояснюй сюжет і механіки наперед.** Єдине, що можна сказати: «грай, як сподобається; думай уголос».
- Мовчки записуй у таблицю нижче години й місця.

## Що записувати

| Тестувальник | Пристрій | Час до першого бою | Де застряг / запитав | Де нудно | Де помер | Дійшов до | Цитата |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | |

Окремо позначай моменти:

- перший раз, коли людина не знала, що робити далі;
- перший вибір перка (чи прочитала описи);
- чи користується ривком і вмінням E без нагадування (скільки хвилин до першого вжитку);
- реакція на заставку боса (пропускає чи дивиться);
- момент, коли людина перестала грати, і чому.

## Після гри: п’ять запитань

1. Що було найкраще?
2. Що було найнуднішим?
3. Що ти не зрозумів(ла)?
4. Чи хотів(ла) б пограти ще? Чому?
5. Що змінити першим?

## Що робити зі знахідками

1. Для кожної окремої проблеми створи issue (шаблон «Відгук після гри» або «Помилка»), додай мітку пріоритету: критична, висока, середня, низька.
2. Рахуй повтори: те, на чому застрягли двоє з п’яти, — висока.
3. У [таблиці задачі 3.6](../wbs/README.md) перерахуй, що береться в роботу, і що свідомо відкладається.
4. Збережи сирі нотатки в `docs/qa/playtests/<дата>.md` (без прізвищ).

## Критерій готовності

- мінімум троє дійшли хоча б до першого боса;
- відгуки зібрано в одному місці (issue чи нотатки);
- кожна знахідка має issue з пріоритетом.
