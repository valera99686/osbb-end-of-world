# Перевірка APK на телефоні

Чекліст для задачі 1.6 і 3.5 з [WBS](../wbs/README.md). Заповнюється на справжньому Android-пристрої: у браузері й емуляторі звук, жести та поведінка WebView інші. Кожен знайдений дефект стає issue на GitHub (шаблон «Помилка»), а тут записується його номер.

Файл для перевірки: <https://github.com/valera99686/osbb-end-of-world/releases/latest/download/osbb.apk>. Перед початком звір SHA-256 із записом у релізі (`certutil -hashfile osbb.apk SHA256` у Windows або застосунок для хешів на телефоні).

## Чекліст

Познач `[x]` те, що працює, `[!]` що працює погано (опиши в таблиці дефектів), `[ ]` не перевірено.

### Встановлення й запуск

- [ ] APK встановлюється (дозвіл на встановлення з невідомих джерел спливає один раз, застосунок називається «ОСББ кінця світу»).
- [ ] Повторне встановлення поверх старої версії зберігає прогрес (стара версія з меншим `versionCode`).
- [ ] Перший запуск показує заставку-вступ і хаб без білого екрана; час від іконки до хабу: ___ с.
- [ ] Заставку можна пропустити; кнопка «Далі» працює дотиком.
- [ ] Іконка й назва в списку застосунків правильні.

### Звук і голос (найризикованіше місце, WebView)

- [ ] Після першого дотику починає грати музика хабу.
- [ ] Голоси в діалогах чутно (повзунок «Голоси» в налаштуваннях змінює гучність).
- [ ] Під час голосу музика стишується й потім повертається.
- [ ] У бою є звуки пострілів, ривка й вміння; музика бою змінюється зі складністю.
- [ ] Кнопка вимкнення звуку в шапці працює й запам’ятовується після перезапуску.
- [ ] Звук не зникає після виходу з гри на головний екран і повернення.
- [ ] Нічого не грає, коли гру згорнуто.

### Керування дотиком

- [ ] Джойстик у лівому нижньому куті рухає будинок плавно, без застрягання.
- [ ] Кнопка «Ривок» працює й показує перезарядку.
- [ ] Кнопка вміння героя (Удар опор, Розряд, Цвітіння, Ревізія та інші) працює й показує перезарядку.
- [ ] Дотик по арені під час заставки боса пропускає її (після півсекунди).
- [ ] Меню, магазин, план будинку, рюкзак і дерево карти прокручуються й натискаються без промахів; кнопки не менші за палець.
- [ ] Системна кнопка «Назад» не виходить із гри посеред бою (перевір і опиши, що вона робить).

### Геймпад (якщо є)

- [ ] Контролер підключається по Bluetooth, будинок рухається лівим стіком або хрестовиною.
- [ ] A або правий тригер: ривок; B або правий бампер: вміння; Start: пауза.
- [ ] Меню керується хрестовиною й кнопками.

### Орієнтація та система

- [ ] Портретна орієнтація: усі екрани вміщуються, нічого не обрізано, кнопки досяжні одним пальцем.
- [ ] Альбомна орієнтація: те саме; поворот посеред бою не скидає бій.
- [ ] Згортання застосунку посеред бою ставить паузу; після повернення бій продовжується.
- [ ] Закриття застосунку смахуванням і новий запуск: «Продовжити» повертає на контрольну точку перед боєм.
- [ ] Режим літака (без інтернету): гра запускається й грається повністю.
- [ ] Дзвінок або сповіщення під час бою не ламають звук і керування.
- [ ] Після 20 хвилин гри пристрій не перегрівається, не вилітає по пам’яті.

### Прогрес

- [ ] Збереження після кожного боя: закрити й відкрити, «Продовжити» працює.
- [ ] Експорт коду збереження й імпорт назад (Налаштування) працюють на телефоні (копіювання в буфер).
- [ ] Денний забіг запускається; після першої спроби день показує «Тренування».
- [ ] Досягнення показують сповіщення й не блокують гру.
