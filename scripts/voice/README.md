# Озвучка реплік

Усі репліки гри озвучує локально OmniVoice (`k2-fsa/OmniVoice`) на відеокарті.
Результат лежить у `public/voice/<id>.ogg` (Opus, моно, 20 кбіт/с) разом зі списком
існуючих файлів `lib/game/voice-manifest.ts`.

`<id>` — хеш пари (голос, текст) із `lib/game/voice.ts`. Гра й генератор рахують
його однаково, тому таблиця реплік у збірку не входить. Репліки зі змінними
словами (`{attempt}`, `{runs}`) не озвучуються. Репліки голови ОСББ існують
у дев’яти варіантах, по одному на кожного героя.

## Перезапуск

1. `npm test` (збирає модулі в `.test-build/`).
2. `node scripts/voice/export-lines.cjs scripts/voice/lines.json`: усі репліки й
   їхній вимовний вигляд (`speech.cjs` розкриває числа, абревіатури, час і ремарки).
3. Python із середовища OmniVoice (потрібні PyTorch з CUDA, `omnivoice`, `ffmpeg` у PATH):

   ```
   python scripts/voice/generate.py --lines scripts/voice/lines.json
   ```

   Корисні прапорці: `--only mechanic,galyna` (лише ці голоси), `--limit 3` (по 3
   репліки на голос), `--force` (озвучити знову), `--refs-only` (лише еталони).

Нові або змінені репліки озвучуються самі, бо їхнього id ще нема. Старі файли без
репліки в грі можна видалити: після генерації `npm test` перевіряє, що манифест
збігається з теками.

## Емоції

OmniVoice вміє вставні теги: `[laughter]`, `[sigh]`, `[surprise-oh]`, `[surprise-ah]`, `[surprise-wa]`,
`[dissatisfaction-hnn]`, `[confirmation-en]`, `[question-*]`. Правила в `tones.cjs` додають їх лише до
тексту, який промовляється: репліка на екрані та її id не змінюються. Правило знаходить репліку за шматком
тексту (`has`) і ставить тег на початку (`lead`), в кінці (`tail`) або замість слова (`swap`); тестів
перевіряє, що кожне правило має свою репліку, а тегів не більше двох. Менше тегів — кращий результат.

`spoken.json` пам’ятає, з якого тексту зроблено кожен запис: змінене правило тону чи нормалізація
(`speech.cjs`) озвучують ці репліки заново без `--force`.

## Голоси

`voices.json`: опис голосу кожного персонажа (`instruct`), зерно (`seed`) і текст
еталонного кліпу. Еталони зберігаються в `scripts/voice/refs/` (у git не входять) і
клонуються для всіх реплік персонажа, тому він звучить однаково. Щоб змінити голос,
правте `instruct` або `seed`, потім `--refs-only --force` і `--only <ключ> --force`.
Домофон і Світанок отримують звуковий ефект у `generate.py` (`EFFECTS`).

Крім `instruct` і `seed`, голос має `speed` (темп; 1 — як спроєктовано), `fx` (фільтри ffmpeg після
синтезу: тембр, ефект) і `target` (бажана висота, Гц). Щоб голоси не зливалися, їх підбирають за цифрами:

1. `python scripts/voice/cast.py --sweep 8 --json cast.json`: по 8 кандидатів на голос у `refs/cast/` із
   замірами (висота, яскравість, темп);
2. `python scripts/voice/cast.py --pick cast.json`: кандидат, найближчий до `target`, стає еталоном;
3. `python scripts/voice/cast.py`: таблиця поточних еталонів і пари, що найбільше схожі;
4. `python scripts/voice/generate.py --lines scripts/voice/lines.json --force --keep-refs`: озвучити репліки
   заново, не чіпаючи вибраних еталонів.

Голос «teenager» у OmniVoice дає зіпсований звук, тому підлітка (Данила) зроблено як «young adult» зі швидким
темпом.
