# Журнал проходів: шаблон

Для задачі 3.7 з [WBS](../wbs/README.md). Копіюй цей файл у `docs/balance/<дата>-playthrough.md` і заповнюй під час гри. Мета: три повні проходи різними героями й зброєю та список місць, де нудно, нечесно чи незрозуміло. Автоматичний аудит (`scripts/balance-audit.cjs`) міряє контрольовані бої, а це ручний протокол живої гри.
