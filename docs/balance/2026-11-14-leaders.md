# Боси й мінібоси зі своїми прийомами: прогони бота 14.11.2026

Що міряли: наскільки важчими стали лідери (0.42.0) для «реактивного» бота (`scripts/pilots.cjs`: тримає дистанцію, виходить із позначених зон, пульсує й ривком уникає ударів, але не читає механік: не б'є антени, не стає на цілу клітину креслення). Бот проходить кар'єру з нового профілю тим самим кодом, що й гра (`scripts/playtime.cjs`).

Три варіанти лідерів, ті самі профілі:

- **A, 0.41.0** — як було: друга фаза на половині здоров'я, без механік, без темпу.
- **B** — A плюс фаза «Лють» (<20%) і темп ×0,9 / ×0,78, без механік.
- **C, 0.42.0** — B плюс механіки 18 лідерів.

Запуск (варіанти A і B — через `node --require`, який вимикає механіку; див. нижче):

```bash
TRACE=1 MAX_RAIDS=40 node scripts/playtime.cjs reactive 4      # C, кожен бій з варіантом лідера
MAX_RAIDS=90 node scripts/playtime.cjs reactive 6              # C, повний прогін для фінмоделі
```

## Що змінювалось у підборі чисел і чому

Бот не читає механік, тому все, що вимагає розуміння, виходило для нього смертельним, і числа довелось знижувати до того, що бот переживає (людина, що розуміє механіку, виграє швидше):

- **Послідовні зони** (парова завіса зверху вниз, п'ять рядів): бот тікав уздовж хвилі й ловив кілька ударів. Тепер усе падає одним моментом з одним проходом: ривок на останньому такті закриває удар, як будь-який інший.
- **Антени й кокони**: «−20% шкоди за антену» (бій 92 → 231 с у боті з максимальним спорядженням) знижено до −12% (→ 153 с); лікування коконів 1% → 0,03% на секунду кожен і не більше чотирьох (мати 148 → 381 с → 261 с); яйця королеви з 3 до 2, лікування від вилуплення 2% → 1%.
- **Креслення Архітектора** (програші 52% → 28%): цілих клітин 3/2/1 → 5/4/3, шкода 1,5 → 0,7 від ваги зони, частота 18 → 22 с. **Відлуння** Хранителя: зони 72 → 62 px, шкода 1,1 → 0,8, частота 11 → 13 с. **Магніт**: 140 → 45 px/с, без шкоди самого поля. **Коренева пастка**: шкода 1,2 → 0,6, телеграф 2,5 → 3,3 с.
- Зони води, магніту й спорової хмари не завдають шкоди самі (`damage: 0`): сповільнюють, тягнуть, лишають слід.

## Як вимкнути механіки для порівняння

`node --require X scripts/playtime.cjs ...`, де `X.cjs` (поза репозиторієм) робить:

```js
const L = require('./.test-build/leader-mech.js');
for (const k of Object.keys(L.MECHANICS)) delete L.MECHANICS[k]; // B
L.leaderTempo = () => 1; // разом із цим і наступним рядком: A
L.leaderPhase = (e) => (e.hp < e.max * 0.5 ? 1 : 0);
```

Профіль 1 варіанта A повторює записані 17 рейдів і 8,4 год, тож вимкнення чисте.

## Кооператив (`scripts/coop-bench.cjs`, 3 гравці, 3 зерна)

Звичайні бої 1-ї й 2-ї локацій і мінібос 1-ї виграні 100%, еліта 3-ї 33%; бос 1-ї локації 33% (було 50–67% до механік), боси 2-ї й 3-ї локацій бот не виграє, як і раніше. Для двох і чотирьох окремо не міряли; числа для партій підкрутить жива гра.

## Чого цими прогонами не перевірено

Відчуття складності для людини: бот не вміє ні пошкодити антенам цілеспрямовано, ні стати на цілу клітину; людина, яка розуміє механіку, виграє швидше, а та, що не розуміє, програє частіше. Потрібен живий прогін; числа лежать у `MECHANICS` (`lib/game/leader-mech.ts`), і їх легко підкручувати. Також не міряли слабкий справжній телефон.
